# 生成AIとの付き合い方

ChatGPT，Gemini，Claude，GitHub Copilot などの生成AIは，Pythonのコードを書いたり，エラーの原因を説明したりすることが得意です．
本講義で使う Google Colaboratory にも Gemini が組み込まれており，コードの自動補完やエラーの説明などを利用できます．

生成AIは，使い方次第で学習を大きく助けてくれる道具です．
一方で，使い方を誤ると「課題は提出できたが，何も身についていない」という状態にもなりかねません．
このページでは，本講義でプログラミングを学ぶうえでの生成AIとの付き合い方をまとめます．

## なぜ自分で書けるようになる必要があるのか

「AIがコードを書いてくれるなら，自分で書けなくてもよいのでは？」と思うかもしれません．
しかし，次の理由から，基礎を自分の力で理解しておくことは今後ますます重要になります．

- **生成AIの出力は正しいとは限らない**
  - 生成AIは，もっともらしいが誤ったコードや説明を出力することがあります．
  - 出力が正しいかどうかを判断し，誤りを直せるのは，内容を理解している人だけです．
- **何を頼めばよいかがわからない**
  - 変数，条件分岐，繰り返し，関数といった基本的な考え方を知らないと，AIに適切な指示を出すことも，返ってきたコードを自分の目的に合わせて修正することもできません．
- **考える力は自分で手を動かすことで身につく**
  - 問題を小さな手順に分解し，順番に組み立てていく力（プログラミング的思考）は，自分で試行錯誤する過程で身につきます．答えを見るだけでは身につきません．

## おすすめの使い方

生成AIを「答えを出してくれる機械」ではなく，**いつでも質問できる家庭教師** として使うのがおすすめです．

- **エラーメッセージの意味を聞く**
  - 例：「`NameError: name 'x' is not defined` とはどういう意味ですか？」
  - まずは自分でエラーメッセージを読んでみて，それでもわからないときに聞きましょう．
- **教材の説明がわかりにくいところを，別の言葉や例で説明してもらう**
  - 例：「Pythonの `for` 文と `range` の関係を，初心者向けに具体例で説明してください」
- **自分で書いたコードを見てもらう**
  - 例：「このコードはもっと読みやすく書けますか？理由も教えてください」
- **自分で解き終わった後に，別の解き方を聞いて比べる**
- **練習問題を作ってもらう**
  - 例：「条件分岐の練習問題を，解答なしで3問作ってください」

AIの回答を読んだら，**必ず自分でコードを実行して確かめ**，なぜそうなるのかを自分の言葉で説明できるか確認しましょう．

## 避けたい使い方

- 課題の問題文をそのまま貼り付けて，出てきたコードを理解しないままコピーして提出する
- エラーが出るたびに，自分でエラーメッセージを読まずにすべてAIに直してもらう
- AIの説明を確かめずに，そのまま正しいものとして信じ込む

このような使い方をすると，その場は乗り切れても力が身につかず，期末試験や今後の専門科目で苦労することになります．

## 利用上の注意

- **個人情報や機密情報を入力しない**
  - 入力した内容は，サービスによってはAIの学習などに利用される場合があります．氏名や学籍番号などの個人情報は入力しないようにしましょう．
- **大学のルールを確認する**
  - 生成AIの利用については，大学全体の方針や，授業ごとのルールがあります．他の授業では，本講義と異なるルールが定められていることもあります．
- **Colaboratory の AI によるコード補完はオフにする**
  - Colaboratory では，コードを書き始めるとAIが続きを自動的に提案する機能が有効になっています．自分で考える練習の妨げになるため，本講義の教材や演習課題に取り組む際はオフにすることを推奨します．
  - 設定方法は [AIによるコード補完をオフにする](#colab-ai-settings)（第1回）を参照してください．

## 本講義での扱い

本講義では，演習課題に取り組む際の生成AIの利用を禁止しておらず，利用したことの申告も求めません．
どのように使うかは，各自の判断に任せます．

ただし，本講義の目的は，課題を提出することではなく，**プログラミングの基礎を自分の力として身につけること** です．
生成AIを使った場合でも，提出するコードについては，

- なぜそのように書くのか
- 各行で何が起きているのか

を **自分の言葉で説明できる** 状態にしてから提出しましょう．説明できないコードは，まだ自分の力になっていないコードです．

期末試験の実施方法や注意事項は，[期末試験に関する情報](exam.md) を確認してください．
